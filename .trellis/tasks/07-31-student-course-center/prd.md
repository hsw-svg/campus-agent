# 学生课程中心

## Goal

在学生端新增独立的“课程中心”，以清晰的课程卡片帮助学生浏览大学通识课程，并为后续进入具体课程学习场景提供入口。

## Requirements

- 学生端左侧菜单新增“课程中心”，与现有学习工作台、校园中心并列切换。
- 课程中心以响应式卡片网格展示多门课程。
- 每张课程卡片至少显示：
  - 课程缩略图
  - 课程名称
  - 开课时间
  - 授课老师
- 默认提供不绑定特定学校身份的大学通识课程，至少包含：
  - 大学英语
  - 形势与政策
- 可补充高等数学、大学计算机基础、大学体育、职业生涯规划等通识课程，使首屏具备完整演示效果。
- 延续项目现有 React、TypeScript、Tailwind CSS、lucide-react 与 Motion 技术栈，不新增重复的组件库。
- 不新增账号、登录、班级、选课或师生权限体系。
- 缩略图应与课程主题有明确视觉区分，同时避免引入学校标识或未经授权的品牌素材。
- 课程必须是后端持久化的真实课程，而非仅用于展示的前端静态卡片。
- 点击课程卡片后应进入对应课程，并将该课程作为后续学习操作的明确上下文。
- 课程缩略图、开课时间和授课老师需纳入共享 API 契约及后端课程模型。
- 课程卡片包含独立的学习按钮：
  - 从未学习过的课程显示“开始学习”。
  - 已有学习记录的课程显示“继续学习”。
- 点击卡片中的“开始学习”或“继续学习”直接进入 AI 学习工作台，并设置当前课程上下文。
- 点击课程卡片的其他区域进入独立课程详情页，而非直接进入 AI 学习工作台。
- 课程详情页至少显示：
  - 课程基础信息
  - 课程章节
  - 学习进度
  - 薄弱知识点
  - 针对薄弱知识点的推荐学习内容
- 课程详情页同样提供“开始学习”或“继续学习”按钮，并与卡片按钮保持一致。
- 学习状态、章节进度和薄弱知识点应来自可持久化的数据，不因刷新页面而丢失。
- 首次点击“开始学习”时记录课程开始时间，后续统一显示“继续学习”。
- AI 学习工作台必须在课程上下文中选择或显示当前章节。
- AI 学习工作台提供明确的“完成本节学习”动作；执行后持久化章节完成状态并更新课程总进度。
- 不以单纯打开页面或聊天次数推断章节完成，避免产生虚假进度。
- 薄弱知识点根据当前课程的 AI 对话或测验结果生成；没有分析依据时显示引导空态，不提供伪造结果。
- 默认通识课程通过显式、幂等的后端初始化接口写入当前学生工作区：
  - 同一默认课程只创建一次。
  - 重复进入课程中心不会重复创建课程或章节。
  - 初始化只补齐缺失的默认课程，不覆盖用户已修改的数据。
- 默认课程至少包括大学英语、形势与政策、高等数学、大学计算机基础、大学体育、职业生涯规划。

## Acceptance Criteria

- [x] 学生端左侧菜单可进入“课程中心”，切换时不使用对话框。
- [x] 课程中心默认展示多门课程卡片，其中包含“大学英语”和“形势与政策”。
- [x] 每张卡片可见课程缩略图、名称、开课时间和授课老师信息。
- [x] 卡片布局在桌面端和移动端均无溢出，信息层级清晰。
- [x] 切换到学习工作台、校园中心后再返回课程中心，页面可正常显示。
- [x] 点击任一课程卡片可进入对应课程，进入后页面能明确显示当前课程。
- [x] 点击课程卡片主体可进入独立详情页，详情页显示章节、学习进度、薄弱知识点和推荐学习内容。
- [x] 未开始课程的卡片与详情页显示“开始学习”，已开始课程显示“继续学习”。
- [x] 点击“开始学习”或“继续学习”可进入带当前课程上下文的 AI 学习工作台。
- [x] 进入 AI 学习工作台后产生的学习状态可在课程中心和详情页中一致体现。
- [x] 默认课程初始化可重复调用且不会产生重复数据，也不会覆盖已有课程内容。
- [x] 刷新页面或重新请求接口后，课程元数据仍可从后端读取。
- [x] 前端 lint 与生产构建通过。

## Existing-system constraints

- 后端已有工作区范围内的 `Course` 实体及课程 CRUD，但当前字段只有名称、描述和时间戳。
- 现有课程实体尚无缩略图、开课时间和授课老师字段。
- 学生端当前未使用课程数据；教师端已在资料和对话场景中使用课程上下文。
- 已确认采用可进入的真实课程，需要扩展共享契约、后端模型、迁移和学生端状态。

## Decisions

- 课程采用后端持久化数据。
- 课程卡片是可进入的真实课程入口。
- 卡片主体进入课程详情页；卡片上的学习按钮直接进入 AI 学习工作台。
- 课程详情页承载课程章节、学习进度、薄弱知识点和推荐学习内容。
- 首次开始学习记录开始时间，章节完成由 AI 工作台中的明确完成动作触发。
- 薄弱知识点来自课程范围内的 AI 对话或测验分析；无依据时使用空态。
- 默认课程按稳定模板标识幂等初始化，仅补缺、不覆盖。
