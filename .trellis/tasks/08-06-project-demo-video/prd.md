# 项目浏览器演示录屏与解说视频

## Goal

制作一段不超过 5 分钟的《智汇校园》功能演示视频：在浏览器中真实操作已部署项目并录屏，按操作时间节点编排中文解说，将解说音频与录屏合成为可播放的最终视频，用于对应赛题提交的“功能演示视频”材料。

## Confirmed Facts

- 赛题要求围绕教师教学、学生学习、院校行政三大岗位，选取 1—2 项校园智能化核心场景，强调本地部署、数据安全、简洁易用和真实流程价值。
- 项目设计方案将教师教学闭环作为比赛主线：匿名学情表 → 班级整体学情研判 → 课堂互动活动包 → 匿名课堂观察/聚合统计 → 追问与教学动作 → 课堂总结导出。
- 赛题评分关注场景适配性、功能实用性、操作便捷性、代码规范性、异常处理能力和文档完整性；设计方案已有对应演示步骤和量化指标。
- 当前 `http://localhost:8080/api/health` 返回 healthy，数据库、聊天模型、嵌入模型和 DeepTutor 均已配置/健康；主机 `localhost:3000` 当前未监听，浏览器演示应优先使用 Compose 暴露的 8080 入口。
- 项目禁止在演示中出现真实学校、教师、学生或联系方式；演示数据应为匿名/虚构数据。
- 用户明确要求：浏览器操作、同步录屏、记录时间节点、按时长生成解说、结合 `docs/赛题要求` 点题、合并音视频、总时长控制在 5 分钟以内。
- 用户已提供录屏 `C:\Users\hsw\Desktop\meeting_01.mp4`。原片约 387.35 秒，1920×1080、15fps，包含 H.264 视频和 32kHz 单声道 AAC 音轨。
- 关键画面抽样显示原片依次覆盖角色选择/产品总览、教师学情分析与结果、课堂互动/课程迭代与 Python 教材、学生学习空间与交互式教材、行政工作台与会议/材料整理等段落；其中存在等待、重复浏览和弹窗停留，需要剪辑。
- 本机可调用剪映安装目录中的 `ffmpeg.exe` 进行视频处理；PowerShell `System.Speech` 可用中文 Microsoft Huihui 语音生成 WAV。无需修改或覆盖原始录屏。

## Requirements

- R1. 以浏览器访问项目真实入口完成一次可复现的功能演示，不通过静态截图或伪造界面替代核心操作。
- R2. 演示优先覆盖教师 P0 闭环中最能体现赛题价值的 1—2 个核心场景，并展示输入、智能处理、结果和可落地成果；若环境或时长限制导致闭环无法完整执行，需在脚本中明确降级路径。
- R3. 录屏应包含清晰的界面操作和关键结果；不得录入真实个人/学校信息、密钥或隐私数据。
- R4. 建立带开始/结束时间的操作节点表，节点至少包含画面动作、可见结果、对应赛题痛点/评分点和解说要点。
- R5. 根据实际录屏时长生成与画面同步的中文解说稿，解说需点明“教师教学提质增效”“轻量化 Skill/AI 智能体”“本地部署与数据安全”“教—学—管融合”等赛题关联，但不得宣称录屏未展示的能力已被验证。
- R6. 生成中文解说音频，并将其与录屏合成为单一视频文件；最终时长 ≤ 300 秒，音画基本同步，输出文件可在常见播放器中播放。
- R6a. 最终视频必须烧录中文字幕；字幕需与解说同步，使用半透明深色背景（可配白字描边）保证浅色页面上仍清晰可读。
- R7. 在最终交付中同时保留可复核的时间节点/解说稿和原始录屏、音频、合成视频（如工具链允许），便于后续修改。

## Acceptance Criteria

- [ ] 浏览器录屏展示真实项目入口及至少一条完整的教师教学智能辅助路径。
- [ ] 录屏/脚本覆盖至少两个可核验价值点：例如匿名学情分析、课堂互动活动包、课堂观察追问、课堂总结导出、角色/资料隔离或异常降级。
- [ ] 时间节点表与视频画面顺序一致，包含总时长统计；最终视频不超过 5 分钟。
- [ ] 解说稿逐段对应节点，并明确引用赛题要求中的场景痛点、部署/安全要求或评分指标。
- [ ] 合成视频同时含录屏画面和中文解说音频，无明显截断、黑屏或音画完全错位。
- [ ] 最终视频含清晰中文字幕，字幕有对比背景或描边，无遮挡关键界面信息且无明显错位。
- [ ] 产物不包含真实学校、教师、学生、联系方式、密钥或未授权隐私信息。
- [ ] 记录所用浏览器入口、运行前提和生成命令/步骤，确保他人可复核。
- [ ] 规划阶段明确剪辑后的目标区间、各区间对应的赛题点和解说字数/语速；用户确认后再进入实际合成。
- [ ] 以用户提供的精确时间点为源坐标生成剪辑版时间轴；00:00–00:02 必须删除，其他长停留需通过跳切或压缩控制总时长。
