# 课程生成流式状态与思考窗口

## Goal

让教师在课程迭代、学情分析及其他智能体任务执行期间及时看到可理解的进展，并尽早看到模型正在生成的正文，减少“页面无响应、必须等后台全部完成”的等待感。

## Background and confirmed facts

- `/api/conversations/{conversation_id}/messages/stream` 已使用 SSE，前端已有 `StreamEvent` 解析和 `useWorkspaceChat` 事件处理。
- 现有协议已经使用 `message_start`、`route_decision`、`tool_status`、`delta`、`artifact`、`done`、`error`；后端 `streaming.py` 的固定事件枚举尚未包含已实际发出的 `route_decision`，需要在本次改造中统一。
- `stream_assistant_reply` 目前会先完成上下文构建和 `executor.execute()`，只在执行器全部返回后发送一次完整 `delta`；因此前端虽有流式连接，课程迭代和通用模型回复仍表现为一次性显示。
- `GenericChatExecutor` 会消费完模型异步迭代器后才返回 `AgentResult`；课程迭代还会完整收集结构化 JSON，学情分析则执行表格解析和统计后才产生结果。
- 前端已经维护 `toolStatus`、`runStatus`、`route` 和 `isAiTyping`，但当前主要作为内部状态或零散文案使用，没有独立、可折叠的过程窗口。
- 既有课程历史要求保持课程/工作区隔离；现有 SSE 的运行、Artifact 和最终消息持久化行为不能被破坏。

## Requirements

### R1. 真实增量正文

- 对支持模型文本输出的任务，后端必须在收到模型片段后立即通过 SSE `delta` 发送，而不是等完整执行器返回后再发送整段正文。
- 前端必须按增量更新当前 assistant 草稿消息，课程迭代的结构化内容在未完成前可以显示可读的生成文本或生成占位状态，最终 Artifact 仍以完整、校验后的结果为准。
- 生成结束、失败、停止和网络中断时，必须沿用现有 `done`/`error`/停止状态语义，不能留下永久 `running`。

### R2. 可理解的智能体过程事件

- SSE 必须提供稳定的阶段状态，用于表达路由、读取资料、调用检索/模型、校验结构化结果、生成成果和完成等阶段。
- 阶段事件可以携带安全的展示摘要、智能体名称、工具名称、状态和可选计数；不得发送模型隐藏的逐字思维链、系统提示词、原始成绩表行或密钥。
- 课程迭代、学情分析和其他现有 `streamMessage` 智能体任务都必须复用同一套事件语义；不另起一套仅服务 PPT 的协议。
- 事件应兼容没有工具调用、没有资料引用、没有 Artifact 的普通对话。

### R3. ChatGPT 风格的小窗口

- 在教师课程对话中，以紧凑的小窗口/卡片展示智能体调用阶段和安全的思考摘要，不把过程日志完整铺在对话消息气泡中。
- 过程窗口应显示当前阶段、已完成步骤和运行状态，支持展开查看步骤；正文仍在原 assistant 消息区域按增量出现。
- 运行中提供停止入口；完成后保留简洁的过程摘要，失败时展示可理解的失败阶段和重试提示。
- 过程窗口应适配课程对话、独立教师智能体和窄屏布局，不新增第二个垂直滚动容器。

### R4. 兼容与可维护性

- 保持现有对话、Artifact、课程上下文、引用和历史聚合行为；不修改数据库结构。
- 共享事件类型在后端序列化、前端 API 类型和 Hook/UI 状态之间保持一致，避免各层继续直接猜测原始字段。
- 对已有 SSE 消费者（包括简历分析）保持兼容；若新增事件，旧消费者忽略未知事件时仍能完成原有流程。

## Acceptance Criteria

- [x] 课程迭代的普通文本分支和其他可读文本回复会在 SSE 片段到达后逐步显示；生成 PPT 的结构化分支会在完整 Artifact 出现前持续显示安全的模型生成/校验阶段，不会展示原始 JSON。
- [x] 学情分析、课堂互动、教学设计等已有智能体任务在执行时能看到统一的阶段状态；学情分析的匿名数据不会出现在过程窗口或 SSE 展示事件中。
- [x] 教师对话中出现紧凑可折叠的过程窗口，窗口外不渲染完整工具日志/隐藏思维链；用户可查看阶段摘要并停止任务。
- [x] 任务完成后过程窗口收敛为完成摘要，Artifact/报告/PPT 仍正常展示、下载和进入历史；失败、停止、刷新或取消不会遗留运行中状态。
- [x] 普通对话、无工具任务、无引用任务和已有简历分析流不回归。
- [x] 后端为新增/调整的 SSE 阶段事件和增量行为补充回归测试，前端通过类型检查和生产构建。

## Out of scope

- 不展示模型隐藏的逐字 Chain-of-Thought、系统提示词、原始附件内容或内部异常堆栈。
- 不引入 WebSocket、数据库迁移、消息队列或新的模型供应商；继续使用现有同源 SSE 和 ChatProvider。
- 不在本需求中重做 PPT 预览、课程历史聚合或智能体路由策略。

## Resolved interaction decision

- 过程窗口运行中默认展开；任务完成后自动折叠为一行摘要，用户可手动展开回看阶段。
