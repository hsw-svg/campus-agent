# 优化学生端交互教材与笔记问答体验

## Goal

让学生可以在较短的阅读视口内连续阅读、定位和提问交互教材，并在离开页面后继续看到自己的问答、笔记和待复习问题；学生端导航只保留当前可用功能。

## Background

- 学生端侧边栏底部目前有未实现的“成绩与分析”“收藏笔记”“设置”链接，点击后没有可用页面。
- `DeepTutorBookPanel` 当前把所有页面块纵向堆叠在工作台主滚动区内，阅读长页面需要反复滚动；上游 DeepTutor 使用固定阅读器、内部滚动和页面块目录来解决长内容定位。
- 当前问答消息只保存在 `DeepTutorBookPanel` 组件内存；离开“交互教材”后组件卸载，重新进入时消息被清空。
- 当前本地学习状态仅保存收藏问题文本，没有保存对应回答；学习空间只显示笔记/问题数量，没有可查看的记录列表。
- 当前仓库不包含 DeepTutor 源码目录；已使用仓库既有的上游核查记录和临时参考副本 `C:\Users\hsw\AppData\Local\Temp\deeptutor-reference` 对照原项目的 Book、Page Reader、Page Outline、Page Chat 和 Learning Space 定义。

## Requirements

### R1. 精简学生端导航

- 从桌面端学生侧边栏移除“成绩与分析”“收藏笔记”“设置”三个无效选项及其不再需要的图标引用。
- 不改变学习中心、课程中心、学习空间、交互教材、校园中心、简历助手和移动端现有入口。

### R2. 交互教材阅读体验

- 桌面端交互教材采用独立的阅读滚动区域，页面高度受当前视口约束，不再让中间内容把整个工作台无限拉长；小屏幕继续采用自然纵向滚动。
- 在当前页面顶部提供轻量的页面块结构导航，可跳转到正文、提示、练习等内容块；导航过长时可横向滚动或折叠，不遮挡正文。
- 保留现有 Markdown 和内容块类型的降级展示、上一页/下一页、完成页、笔记编辑和错误/加载/空状态。
- 页面切换时恢复该页面上次的问答和笔记，不把其他页面的问答混入当前上下文。

### R3. 页面问答持久化与文案

- 问答消息按工作空间、书本、页面保存到现有本地学习状态；离开交互教材、切换学生端菜单或刷新浏览器后，重新打开同一页面仍可查看既有用户问题和回答。
- 继续保存待复习问题，并将回答内容与问答历史一起保存；同一问题重复提交不产生重复的收藏问题记录。
- 保存当前页面的 DeepTutor session id（若上游返回），重新进入页面后可继续同一上下文；没有 session id 时仍可正常显示本地历史并开启新会话。
- “清空”需要同时清除当前页面的本地问答历史；关闭或切换页面时必须清理未完成的 WebSocket。
- 提问中只显示面向学生的“正在回答…”或等价文案，不显示“DeepTutor 正在回答/处理”等内部服务名；流式文本、错误和完成状态仍需反馈。

### R4. 学习笔记与待复习问题可见

- 在现有“学习空间”中将只有数量的“学习笔记”和“待复习问题”卡片升级为可浏览的记录列表，至少展示最近记录、正文摘要和关联教材/页面信息。
- 点击笔记或问题可回到对应交互教材，并优先打开对应书本和页面；无对应书本时显示可理解的降级状态。
- 支持记录为空、记录损坏和当前没有 DeepTutor 书本等状态，不影响课程学习中心。
- 不新增“收藏笔记”菜单；把笔记和问题入口收敛到学习空间与交互教材现有页面。

## Constraints

- 不新增账号、登录、JWT、权限、多租户或新的数据库表；继续使用现有工作空间 token 后缀隔离的浏览器本地状态。
- 已确认本轮只要求当前浏览器内恢复问答、笔记和待复习问题，不实现跨设备或跨浏览器同步。
- 浏览器只能通过当前 FastAPI 的同源 `/api/deeptutor/*` 访问 DeepTutor，不能直连 8001；不改变后端适配器和容器编排。
- 复用 React 19、TypeScript、Tailwind、lucide-react、现有 `src/api.ts` 和 `useDeepTutorStudyState`；不引入新的状态管理或 UI 框架。
- UI 遵守根目录 `DESIGN.md` 的层级、间距、卡片、状态和响应式约束，同时保留“智汇校园”的现有品牌色和中文语境。

## Acceptance Criteria

- [ ] 桌面端侧边栏不再显示“成绩与分析”“收藏笔记”“设置”，且相关无用图标不再被引用；其他导航行为不回归。
- [ ] 桌面端打开长页面时，中间阅读区在视口内独立滚动；页面块结构导航可以定位到当前页面的内容块；移动端可正常阅读。
- [ ] 在同一浏览器中提问并收到回答后，切换到其他学生菜单再返回同一书本/页面，原问题和回答仍可见。
- [ ] 刷新浏览器后同一页面的问答、笔记、待复习问题和最近阅读位置仍可恢复；清空问答后刷新也不会恢复已清除内容。
- [ ] 提问过程中不出现包含“DeepTutor 正在回答/处理”的学生操作文案，且 WebSocket 错误、完成和卸载清理行为保持可用。
- [ ] 学习空间可以直接查看最近笔记和待复习问题，并能打开其关联书本/页面；空态与异常态稳定。
- [ ] `npm.cmd run lint` 和 `npm.cmd run build` 通过；相关后端 DeepTutor 集成测试不受影响。

## Out of Scope

- 不实现上游 DeepTutor 的书本提案审核、脊柱编辑、区块拖拽/重编译、Notebook/Question Bank 服务端管理或跨设备同步。
- 不把临时的 DeepTutor 上游源码复制进本项目，也不复制其 Next.js 页面和样式。
