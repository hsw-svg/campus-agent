# 学生校园中心资讯

## Goal

在学生工作台提供独立的“校园中心”，让学生无需离开工作台即可发现学校最新新闻、活动和公文，并能跳转到学校官网查看权威原文。

## Background

- 目标入口是学生工作台左侧菜单新增的“校园中心”，不创建营销落地页或独立资讯系统。
- 资讯内容以学校官方站点为权威来源，系统只做聚合、分类、摘要展示和原文跳转。
- 外部官网的延迟或故障不得阻断学生助手首页和对话能力。
- `docs/赛题要求.md` 明确规定演示中不能出现具体学校信息，否则扣分；实现必须区分可配置的真实部署来源与学校中立的默认/演示呈现。
- 学习中心继续专注对话、快捷学习入口和资料操作；校园资讯通过左侧菜单切换到独立内容视图，不嵌入聊天空态、聊天气泡、输入框或右侧资料选择器。
- 当前 Compose 只有 PostgreSQL，没有 Redis；仓库没有通用 HTTP 缓存或校园门户集成，也没有学校名称、官网域名配置。
- 现有 Bing Search 只能作为通用搜索适配器，不能证明内容来自权威官网，因此不应作为本功能的主数据源。
- 学生端不得读取行政工作区内部通知；本功能只允许读取无需登录的公开官网栏目。

## Requirements

- 首页至少区分学校新闻、校园活动、学校公文/通知三类信息，并展示标题、发布日期和来源栏目；真实资讯还须提供官方原文链接。
- 资讯按发布时间倒序展示；如果来源提供可解析的活动结束时间，已结束活动不得挤占首屏，否则按来源发布日期排序。
- 真实资讯点击后跳转学校官网原文，不在本系统复制完整公文或伪装为官方发布渠道；通用示例不可点击。
- 第一期支持 RSS/Atom 源和通过环境配置 CSS 选择器的公开 HTML 栏目页，只采集标题、发布日期、栏目、列表摘要和原文链接。
- 第一期不抓取详情页正文、附件或图片；列表页没有摘要时允许只展示标题、日期和栏目。
- 所有原文链接必须属于配置的官方域名，重定向后的最终 URL 也必须重新校验。
- 后端负责获取、规范化和缓存官方数据；前端不得在浏览器中直接抓取学校官网。
- 官网不可用、解析失败或部分栏目异常时，返回可识别的降级状态和最近一次成功缓存，不得导致首页白屏或对话功能不可用。
- 资讯缓存持久化到 PostgreSQL；首页请求优先返回最近成功缓存，缓存超过 30 分钟时触发后台刷新，冷缓存允许一次有超时上限的同步获取。
- 官网刷新失败时继续返回最近成功缓存并标记降级；超过 7 天的缓存不得继续作为“最新资讯”展示。
- 信息源 URL、刷新频率和缓存时长通过配置管理，不硬编码密钥或环境专属地址。
- 具体学校名称、Logo 和官网域名不得硬编码；未配置真实来源时展示不含具体学校标识且不显示“演示内容”字样的中立示例，真实部署通过环境配置接入官方来源并整体替换示例。
- 通用示例条目不可点击且不伪造官方原文 URL；配置真实官网后，真实条目才显示外链入口并跳转经过官方域名校验的原文。
- 左侧菜单新增“校园中心”；点击“学习中心”和“校园中心”可在对话工作区与资讯视图之间切换，不清除已有对话内容。
- 校园资讯只在校园中心展示；校园中心不显示聊天消息、输入框或学习资料侧栏，学习中心不显示校园资讯。
- 桌面端按学校新闻、校园活动、公文/通知三栏展示，每类首屏最多 3 条；移动端使用三类切换控件，每次最多展示当前分类 3 条。
- 保持现有 React、TypeScript、Tailwind CSS、lucide-react、Motion 与 Fetch API，不引入重复组件库。
- 本任务不新增账号、登录、订阅推送、评论、点赞或学校内容发布后台。

## Acceptance Criteria

- [ ] 学生可通过左侧“校园中心”进入资讯视图，并可切回“学习中心”继续原有对话。
- [ ] 校园中心能够按新闻、活动、公文/通知分类浏览中立示例，或在配置来源后浏览官方站点的最新条目。
- [ ] 每条真实资讯具有稳定的标题、日期、栏目、官方原文 URL 和必要的展示摘要，非法或非官方 URL 不进入结果；通用示例明确没有原文 URL。
- [ ] 官网超时、返回异常或结构变化时，API 和前端有经过测试的缓存/空态/降级行为，学生首页其他功能保持可用。
- [ ] 桌面与移动视口下资讯区域可扫描、可点击且不遮挡现有学生工作台控件。
- [ ] 桌面端可同时扫描三类各最多 3 条资讯；移动端可在三类之间切换并查看当前分类最多 3 条资讯。
- [ ] 学习中心不渲染校园资讯；校园中心不渲染聊天消息、输入框或资料侧栏，切换视图不丢失已有对话状态。
- [ ] 未配置官网来源时可看到不含具体学校标识的通用示例；配置真实来源后结果中不再混入示例条目。
- [ ] 通用示例没有可点击的原文入口；真实资讯具有清晰的外链交互，并且只跳转到允许的官方域名。
- [ ] 后端单元/API 测试、前端 lint/build 和直接相关的浏览器冒烟通过。

## Out of Scope

- 抓取非官方自媒体、社交平台或搜索引擎转载内容。
- 具体院校详情页正文抓取、正文清洗/切分、向量索引和校园资讯 RAG；这些作为后续独立阶段规划。
- 在本系统中编辑、审批或发布学校公文和活动。
- 个性化推荐、已读状态、收藏、订阅和消息推送。

## Technical Notes

- 目标学校官网及三个栏目对应的权威 URL/数据接口由后续部署环境提供，不写入仓库，也不阻塞中立示例和接口实现。
- 该功能跨越外部官网集成、后端缓存/API 和学生端首页，属于复杂任务，规划阶段需要 `design.md` 与 `implement.md`。
