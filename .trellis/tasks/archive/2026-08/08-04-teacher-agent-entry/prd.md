# 教师独立智能体入口

## Goal

让教师无需先选择或创建课程，也能从教师工作台侧栏直接启动“学情分析”“课堂互动”“课程迭代”三个独立智能体，以不关联课程的普通任务形式完成一次性教学工作，同时复用现有课程内相同能力的接口、页面组件和成果呈现。

## Background

- 教师工作台左侧当前包含“导航”和“最近对话”区域。
- 课程空间内已存在学情分析、课堂互动与课程迭代三个工作流能力。
- 学生端已有教材、简历助手等独立智能体入口，可作为入口形态和独立任务体验的参考。
- 本任务需要调整教师侧信息架构，但不新增账号、权限、班级或工作区等业务能力。
- 仓库已注册 `learning_analysis`、`classroom_interaction`、`course_iteration` 三个教师 Agent，并支持前端通过显式 `agent_id` 进入既有 AgentRun/SSE 链路。
- 当前侧栏“最近会话”是单个导航按钮；课程会话、无课程任务历史及顶部“智能体历史”聚合入口是独立机制，因此替换该按钮不要求删除会话数据或恢复能力。
- 现有实现中，学情分析要求显式匿名表格；课堂互动要求主题、教学目标、总时长以及课程资料或学情成果；课程迭代要求显式资料选择。本任务需要只针对教师独立 Agent 工作流放宽后两者的资料要求，课程内既有资料策略保持不变。

## Requirements

- 将教师工作台侧栏的“导航”标题改为“教师 Agent”。
- 移除侧栏“最近对话”展示，改为三个固定智能体入口：学情分析、课堂互动、课程迭代。
- 三个入口均可在未关联课程的情况下启动独立任务。
- 独立智能体复用课程内对应功能的 API、业务流程、页面组件和成果展示，避免形成两套实现。
- 独立任务默认 `course_id = null`，不得隐式绑定当前课程；课程内原有入口和行为保持可用。
- 入口样式与交互可参考学生端教材、简历助手等智能体入口，同时保持教师工作台现有品牌与布局。
- 独立任务应进入现有任务/会话生命周期，并能正确生成、恢复和展示对应智能体的消息与成果。
- 侧栏改造只替换“导航 / 最近会话”这组入口，不删除课程树、无课程任务历史和现有“智能体历史”聚合入口。
- 点击任一固定智能体入口后先进入对应的独立准备页，不立即创建会话或发送默认提示；教师补齐必要输入并提交后，才创建并执行 `course_id = null` 的独立任务。
- 三个准备页分别承载对应输入：学情分析选择/上传匿名表格；课堂互动填写教学主题、教学目标并可选上传资料；课程迭代填写教学主题、迭代目标并可选上传资料。
- 学情分析至少需要一份符合现有格式约束的匿名表格；课堂互动与课程迭代必须支持仅凭主题和目标运行，不得因没有课程或附件而拒绝执行。
- 独立课堂互动的总时长为选填项，默认 45 分钟；教师可在准备页覆盖该值，提交时必须将最终时长明确传给既有互动生成逻辑。
- 后端资料约束的放宽必须限定在教师独立 Agent 工作流标识下；课程内入口继续沿用当前课程资料注入和验证行为。
- 准备页新增文件在提交前仅保存在浏览器内存，不创建会话、不上传服务端；点击“开始执行”后创建 `course_id = null` 的会话，将文件上传为该会话的任务附件，全部上传成功后再调用指定 Agent。
- 离开准备页或刷新页面时，尚未提交的本地暂存文件不保留；不得将其静默保存为教师通用工作区资料。
- 教师 Agent 三个固定入口采用紧凑的“图标 + 标题”形式，不展示详细描述，减少侧栏纵向占用。
- 独立 Agent 准备页覆盖教师工作台右侧主区域，不沿用嵌入内容卡片的视觉层级；覆盖期间隐藏并禁用工作台/资料/课程管理、课程标题、状态按钮和智能体历史等课程工作区控件。
- 覆盖页使用低边框、磨砂虚化材质弱化底层课程内容，并在右上角提供清晰的关闭按钮；关闭后恢复进入前的工作台状态。

## Acceptance Criteria

- [ ] 教师侧栏显示“教师 Agent”，不再显示“导航”和“最近对话”标题。
- [ ] 侧栏明确展示学情分析、课堂互动、课程迭代三个可操作入口。
- [ ] 点击任一入口只打开对应准备页；未提交前不创建会话、不产生 AgentRun，也不发送模型请求。
- [ ] 准备页文件在提交前不会出现在服务端会话或工作区资料中；提交后归属于新建的无课程会话，上传完成后才发起 Agent 请求。
- [ ] 任一附件上传失败时不启动 Agent，并给出可重试的明确错误；不得产生缺少所选资料的模型请求。
- [ ] 学情分析未提供匿名表格时不可提交，并显示明确的输入提示。
- [ ] 课堂互动和课程迭代在没有任何附件时，仅填写主题与目标即可成功启动对应 Agent；添加附件时仍通过显式选择传入。
- [ ] 课程内课堂互动和课程迭代的现有资料选择及上下文行为保持不变。
- [ ] 独立课堂互动未填写时长时按 45 分钟执行；填写有效时长时按教师输入执行。
- [ ] 从任一入口新建任务时，即使当前存在已选课程，新任务仍默认不关联课程。
- [ ] 三个独立智能体能够完成与课程内对应能力一致的核心流程，并复用既有接口和组件。
- [ ] 课程内原有三项能力及课程关联任务不受影响。
- [ ] 独立智能体任务可通过现有会话机制恢复，恢复后智能体类型、消息和成果正确。
- [ ] 桌面和窄视口布局可用，键盘焦点与可访问名称完整。
- [ ] 侧栏三个 Agent 入口只显示图标和标题，高度紧凑且选中态仍清晰。
- [ ] 准备页覆盖整个右侧主区域，顶部课程导航与智能体历史不可见、不可交互，右上角关闭后能恢复原页面。
- [ ] 前端 lint/build 通过；涉及后端契约或路由变化时补充并通过相应 pytest 回归。

## Out of Scope

- 新增教师身份、权限、班级或工作区模型。
- 重做课程空间已有三项能力的业务逻辑。
- 新增与现有任务/会话体系并行的持久化模型。
