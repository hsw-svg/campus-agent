# 按课程内容匹配 PPT 模板并填充生成

## Goal

提升课程迭代生成课件的视觉完成度：系统根据课程内容和模板名称/描述，让 LLM 从受控模板集合中选择合适的 PPTX 模板，并在保留模板原有视觉设计的前提下填充结构化课程内容，生成可正常打开、可继续编辑的 PowerPoint 文件。

## Background

- 现有课程迭代链路已经生成 `slide_deck` 结构化成果，并通过 `GET /api/artifacts/{id}/export?format=pptx` 导出 PPTX。
- 当前 `apps/api/app/skills/slide_deck_pptx.py` 使用关键词表 `_THEME_KEYWORDS` 选择主题，并用 `python-pptx` 向模板布局添加标题页、正文页和双栏页。
- 当前仓库原有 `academic_blue`、`tech_purple`、`vibrant_green`、`warm_orange` 四份程序生成模板为空壳模板，不再作为本期生成来源。
- 用户已上传两份目标模板：“AI科技”（科技蓝配色）和“商业计划书”（商务蓝配色）。本期先只支持这两份模板，后续再扩展模板数量。
- “AI科技”模板为 16:9，共 32 页、2 个母版和 6 个基础版式（Title Slide、Agenda、Section Header、Title Only、Blank、Closing）；可识别出封面、目录、章节、多个内容构图、结束页和模板使用说明页。
- “商业计划书”模板为 16:9，共 21 页、2 个母版和 3 个基础版式；可识别出封面、目录、章节、多个商务内容构图、结束页和模板使用说明页。
- 两份模板的大量视觉内容与可替换文字位于源幻灯片的本地文本框/组合图形中，而不是标准母版占位符。仅通过 `presentation.slides.add_slide(layout)` 无法复用完整设计，必须复制登记过的源页面并按精确对象映射替换。
- 两份模板均包含“第一PPT”示例署名、示例业务内容、网址以及对在线付费下载、网络转载和线上线下传播的限制；用户确认尚未取得比赛展示或分发授权。本期仅用于开发阶段验证模板匹配与内容填充链路，比赛提交前必须替换为自有或无商业限制的 PPTX 模板。
- 现有 `slide_deck.data` 已包含主题、受众、教学目标、课程时长、上下文信号和逐页结构，可作为模板匹配及内容映射输入。
- 本任务是 `.trellis/tasks/07-26-slide-deck-generation` 的子任务。

## Requirements

1. 建立受控模板清单，本期仅登记“AI科技”和“商业计划书”两份模板；每个模板至少包含稳定 `template_id`、面向用户的模板名称、适用场景描述、PPTX 文件位置和支持的页面版式。
2. 模板选择由现有 Chat/LLM 适配器完成；模型只能返回清单内的 `template_id`，不得输出任意文件路径。
3. 模板匹配输入至少包含课程主题、受众、教学目标和模板名称/描述；模板选择字段缺失、选择失败或返回未知 ID 时必须确定性回退到默认模板。整个课件生成模型未配置时继续沿用现有生成失败行为，不在本任务内伪造课件内容。
4. 课件内容继续使用结构化 `slide_deck.data`；生成器根据每页内容选择模板中实际存在且已登记的版式，并填充明确的文本槽位。
5. 导出时保留所选模板的页面尺寸、背景、配色、字体、装饰元素、页眉页脚和既有布局；只改写登记为内容槽位的对象。
   - 输出页面必须来自登记源页面的复制，不得只从空母版布局重新搭建近似样式。
   - “第一PPT”示例署名、模板教学示例、示例业务数据和网址必须按对象级映射处理，不得用全局文本清空规则误删视觉组件。
6. 对标题、正文、双栏等文本设置长度/条目上限。内容不适配时优先缩短、换版式或拆页，不以覆盖装饰元素或产生明显溢出作为兜底。
7. 模板清单、匹配结果与 PPTX 导出保持后端模块边界清晰；不新增账号、权限、工作区或其他无关业务能力。
8. 保持现有 Artifact 导出接口及前端下载流程兼容；已有 `slide_deck` 数据在缺少新增字段时仍能导出。
9. 为模板选择成功、非法选择回退、默认模板回退、模板文字填充、页数和 PPTX 可打开性补充自动化回归。
10. “AI科技”默认面向 AI、计算机、工程技术等科技类课程；“商业计划书”默认面向商科、创新创业、项目方案等商务类课程。LLM 可结合课程语义选择，但不得选择清单外模板。
11. 模板元数据必须表达授权/使用范围；“AI科技”和“商业计划书”登记为 `development_only`，使后续替换模板文件和许可状态时无需重写 LLM 选择、页面规划或导出链路。
12. 本期实现及文档不得声称这两份模板可用于比赛提交、商业发布或公开分发；比赛前更换合规模板作为独立交付门槛。
13. 本期不增加生产环境硬性禁用开关，也不阻止 `development_only` 模板生成或下载；由用户在比赛提交前人工确认并替换为合规模板。
14. 模板选择遵循以下优先级：
    - 用户消息明确包含“AI科技”或“商业计划书”模板名称时，直接采用该模板，不再让 LLM 覆盖用户选择。
    - 用户未指定模板时，LLM 根据课程主题、受众、教学目标及受控模板名称/描述返回一个 `template_id`。
    - 用户给出无效/模糊名称时进入 LLM 自动匹配；模型结果无效或匹配失败时回退“AI科技”。
15. 已登记源页面构图允许重复使用，以支持生成页数超过可复用构图数量的课件；相邻内容页应尽量避免同一构图，重复时仍只能修改登记槽位。
16. 本期只做文字内容填充。含有与源主题强绑定的产品截图、工具 Logo、物联网数据图或不可泛化图片的页面不登记为通用内容页；抽象背景和纯装饰素材可随源页面保留。
17. 同一课程迭代会话的后续修改在没有明确模板名称时沿用上一版 `template_id`；明确指定另一模板时切换。只有首次生成且未指定模板时才由 LLM 自动匹配。
18. 若 `slides[0].layout == "title"`，该页直接映射模板封面，不额外添加重复封面；历史数据首张不是 `title` 时才根据顶层 topic/audience/objective 合成封面。
19. 本期不使用 PNG、截图或服务端渲染方式预览最终 PPT；模板视觉效果仅通过下载 `.pptx` 查看。现有结构化课件内容预览保持不动，前端直接预览 PPTX 作为后续独立需求。

## Acceptance Criteria

- [ ] 给定两个已登记模板及一份课程内容，LLM 返回清单内 `template_id` 后，导出结果使用对应模板，而非现有关键词主题规则。
- [ ] 科技类课程样例选择“AI科技”，商务/创业类课程样例选择“商业计划书”；语义模糊时按配置的默认模板生成。
- [ ] 消息明确写出“AI科技”或“商业计划书”时，无论课程主题为何均采用指定模板；无效名称不会被当作文件路径或未知模板加载。
- [ ] 同一会话追问修改但未指定模板时保留上一版模板；明确指定另一模板时生成的新版本切换模板。
- [ ] 模型生成结果中的模板 ID 未知、为空或无效时，系统把模板选择回退到“AI科技”并记录选择来源；已有历史 Artifact 即使没有模板字段也能使用默认模板完成导出。
- [ ] 生成的 PPTX 可被 PowerPoint 正常打开，页面数量与生成策略一致，标题、正文、双栏等内容写入正确槽位。
- [ ] 当首张结构化页面为 `title` 时，下载 PPTX 页数与 `slides` 数量一致且没有重复封面；无 title 页时仅补一张封面。
- [ ] 模板原有背景、字体层级、色彩、装饰、页脚和页面尺寸得到保留，最终文件中不存在未处理的可见示例文字或空白内容占位符。
- [ ] 最终课件不包含未被课程内容替换的 AI 培训、物联网、第一PPT 演讲人、示例网址或模板授权说明页；若模板授权要求保留署名，则按授权条件保留，而不是由程序自行猜测。
- [ ] 长标题和较多正文的测试样例不会产生明显文本溢出或覆盖模板装饰。
- [ ] 生成页数超过可复用构图数量时仍能完成导出，且相邻内容页在存在其他适配构图时不连续重复同一源页面。
- [ ] 输出不保留与课程无关的豆包、DeepSeek、物联网产品、原始示例图表等主题性内容；本期无需新增或替换课程图片。
- [ ] 未包含新增模板选择字段的历史 `slide_deck` Artifact 仍可通过现有接口导出 PPTX。
- [ ] 相关后端 pytest 通过；若前端契约未变化，则无需修改前端，否则 `npm.cmd run lint` 与 `npm.cmd run build` 通过。
- [ ] 模板注册信息能识别两份当前模板为 `development_only`，且替换为新 PPTX 与对应对象映射时不需要修改模板选择协议。
- [ ] 当前两份开发模板无需额外环境变量即可在现有本地/Compose 流程中生成和下载；任务文档保留比赛前人工替换检查项。
- [ ] 本期不新增 PPTX 转 PNG、逐页截图或预览接口；教师可通过现有下载入口获得并打开最终 PPTX。

## Out of Scope

- 在线模板上传、模板商店和模板管理后台。
- 用户在前端手动编辑单页元素或拖拽排版。
- Google Slides、WPS 云文档或第三方在线演示文稿同步。
- 前端直接渲染/预览最终 PPTX，以及任何 PNG/截图式课件预览。
- 用生成式图片替换模板既有品牌素材，或重绘模板视觉系统。
- 自动检索、生成或替换课程图片、图表和视频；本期仅填充文字。
- 本期新增第三种及更多模板；只保留后续可扩展的登记机制。
- 为当前两份模板取得授权；本任务仅记录开发期限制，授权或合规模板采购不在代码实现范围内。
