# 修复教师智能体历史栏布局稳定性

## Goal

修复教师工作台右侧“智能体历史”面板首次打开时某个智能体图标不显示、点击智能体后面板内容宽度发生变化的问题，使桌面侧栏和窄屏抽屉在打开、切换智能体及内容高度变化时保持完整、稳定和可操作。

## Background

- 教师工作台同时定义了桌面右侧栏和窄屏抽屉两种智能体历史容器。
- 当前打开状态会让两种容器同时挂载 `TeacherAgentHistoryPanel`，仅依靠响应式 CSS 隐藏其中一个。
- 两个面板实例内部使用相同的 Motion `layoutId`；固定宽度容器与内部内容还存在重复纵向滚动。
- 用户可见症状是首次打开时一个智能体图标缺失，点击智能体后图标恢复，但面板整体可用宽度随之变化。

## Requirements

- 同一视口状态下只能存在一个可参与布局和共享动画的智能体历史面板实例，避免隐藏实例干扰 Motion 共享布局。
- 五个智能体入口在面板首次打开时必须全部显示图标、名称和记录数；无需额外点击触发修复。
- 切换任意智能体时，面板外框、导航区域及内容区域的可用宽度必须保持稳定。
- 只保留一个明确的纵向滚动责任层；内容增减或课堂互动工作流出现时不得通过滚动条切换造成横向跳变。
- 保留桌面固定侧栏和窄屏右侧抽屉的既有入口、关闭行为、内容功能、选中动画和历史操作能力。
- 修复不得改变智能体分组、历史筛选、成果展示、快速操作、删除和导出等业务逻辑。
- 尊重减少动态效果设置，并保持键盘焦点和可访问名称完整。
- 打开历史详情时，页面背景应有明显的暗化与模糊层，弹窗主体和标题栏保持不透明，标题、智能体、状态和时间信息清晰可读。
- 历史详情标题栏右上角提供高对比度、易识别的关闭图标按钮，并保留可访问名称。
- 保留工作区中其他未提交或已暂存的用户改动，不混入本任务修改。

## Acceptance Criteria

- [ ] 桌面宽度首次打开智能体历史栏时，五个智能体图标均立即可见。
- [ ] 窄屏首次打开右侧抽屉时，五个智能体图标均立即可见。
- [ ] 连续切换全部五个智能体，图标、名称和计数始终完整，无闪烁或消失。
- [ ] 切换前后面板外框宽度不变，导航网格和主要内容区域无横向跳动。
- [x] 打开与关闭面板不会在 DOM 中留下两个具有相同共享布局标识的活动实例。
- [ ] 长历史、空历史和课堂互动工作流三种内容高度下均只有预期的纵向滚动，不出现双滚动条。
- [ ] 桌面和窄屏的打开、关闭、历史查看、删除、导出及快速操作保持可用。
- [ ] 打开历史详情时背景暗化并模糊，标题栏内容不受底层页面干扰且标题文字清晰可读。
- [ ] 标题栏右上角关闭按钮具有明显的背景、边界和图标，点击后可关闭历史详情。
- [x] `npm.cmd run lint`、`npm.cmd run build` 和差异格式检查通过。

## Out of Scope

- 修改智能体分类、历史数据接口或后端存储。
- 重做智能体历史面板的信息架构和业务能力。
- 调整教师工作台其他侧栏、课程树或聊天区域的功能。
