# 课程中心与星球学习中心联动

## Goal

将课程中心作为学生选课与自建课程入口，将“开始学习”后的课程持久化为学习中课程，并在学习中心通过星球轨道呈现课程、进度和章节；学生可基于主题或已上传课程资料调用 Tutor 创建并绑定交互教材，完成“创建课程 → 创建教材 → 开始学习 → 章节问答/阅读”的真实闭环。

## Background

- 学生工作区目前调用 `initializeDefaultCourses()` 加载课程，它会向匿名学生空间幂等写入六门模板课程；课程中心的固定感来自后端模板种子，而非纯前端假数据（`apps/web/src/components/StudentWorkspace.tsx:184`、`apps/api/app/services/student_courses.py:23`）。
- 产品决定保留六门模板课程作为新学生的示例目录，同时允许学生自建课程；模板仍由后端统一维护。
- 学习中心目前接收完整课程列表，并以第一门课程兜底，导致未开始课程也出现（`apps/web/src/components/StudentOrbitHome.tsx:82`、`apps/web/src/components/StudentOrbitHome.tsx:128`）。
- 后端已有 `StudentCourseProgress` 和课程/章节开始接口，可作为“正在学习”与进度的唯一事实来源，无需新增学习清单表（`apps/api/app/courses/models.py:57`、`apps/api/app/api/courses.py:156`）。
- 通用课程创建 API 已存在，但学生端没有入口；学生新建课程默认没有章节（`apps/web/src/api.ts:617`）。
- 课程资料上传已支持按课程触发 DeepTutor 知识库构建；交互教材已支持按主题和知识库生成，但尚未绑定本地课程。
- 运行中的 Tutor 返回稳定的 `book_id → chapter_id → page_ids` 目录结构；主应用、PostgreSQL、独立 `deeptutor` 和 Neo4j 容器已确认健康。

## Requirements

### R1 课程中心与课程创建

- 课程中心展示当前匿名学生工作空间的后端课程，包括六门模板课程与学生自建课程；前端不得维护第二份固定课程列表。
- 学生可在课程中心创建自定义课程，至少填写课程名称，可选填写课程说明。
- 新建课程保存成功后立即出现在课程中心；未开始学习前不得出现在学习中心。
- 课程卡片点击进入课程详情；“开始学习”是将课程加入学习中心的明确动作。

### R2 学习中心课程总览

- 每次默认进入学习中心（首次进入或从顶部导航重新进入）都展示课程总览，不自动恢复并占用某一门历史课程视图。
- 中央主星球外围仅展示 `started=true` 的课程；课程名称、进度数值和可访问状态由 HTML 呈现。
- 每门课程通过外围进度光圈表达 `progress_percent`，且不能只依靠颜色传达进度。
- 点击课程后加载课程详情并切换为该课程章节星图，不重复执行“开始学习”。
- 没有正在学习课程时展示空状态和前往课程中心入口。

### R3 课程章节星图与对话

- 课程视图外围展示后端真实章节，不使用固定章节兜底。
- 点击章节后仍停留在学习中心，选择该章节为课程对话上下文，并恢复该课程/章节的最近对话（如有）。
- 课程视图提供返回课程总览动作；切换课程或章节不得串用课程上下文、教材映射或历史对话。
- 章节有 Tutor 页面映射时展示“进入教材学习”，点击后才进入绑定教材页面；单击章节本身不得突然跳离星图。
- 零章节课程仍可基于课程元数据问答，但需引导学生先创建教材生成章节。

### R4 Tutor 教材创建与课程绑定

- 学生可从自建课程详情或学习中的课程视图输入学习主题，调用 Tutor 创建交互教材。
- 已上传课程资料且知识库可用时，教材创建默认使用该课程稳定知识库；没有资料时仍可按课程名称、说明和用户主题生成。
- 创建结果须将 Tutor `book_id` 持久绑定到课程，并将 Tutor 目录同步为本地课程章节；学习目标映射为知识点，摘要映射为章节说明，`page_ids` 保留为教材入口映射。
- 自建零章节课程同步 Tutor 目录时创建本地章节；已有模板章节不得被无提示删除或破坏既有学习进度。模板课程绑定教材时按顺序映射可对应页面，未对应章节保持无教材入口。
- 同一课程的首次教材绑定属于本期范围；替换/重建已绑定教材不提供用户入口，避免破坏进度和历史对话。
- Tutor 故障时保留已创建课程与已上传资料，返回稳定错误并允许重试，不写入半完成的本地教材映射。

### R5 真实集成回归

- 使用当前 Docker 主应用和独立 Tutor/DeepTutor 容器验证创建课程、上传资料/创建教材、开始学习、课程总览、章节选择、教材页面和课程问答。
- 测试数据使用独立匿名学生工作空间；验证结束后清理本次创建的课程、附件、Tutor 教材和知识库（在 Tutor 提供安全删除能力时），不得破坏现有演示数据。

## Acceptance Criteria

- [ ] AC1（R1）：课程中心保留六门模板课程并可新增自建课程；刷新后数据仍存在，前端无固定业务课程数组。
- [ ] AC2（R1、R2）：新建课程未开始时不在学习中心；点击“开始学习”后立即出现，刷新后仍为学习中。
- [ ] AC3（R2）：默认学习中心以主星球和多个已开始课程为总览；每门课程同时显示进度光圈、百分比和课程名。
- [ ] AC4（R2、R3）：点击课程切换真实章节星图；返回总览、切换课程和切换章节均不串状态。
- [ ] AC5（R3）：点击章节选中课程/章节对话上下文并恢复对应历史；刷新后历史仍可从最近对话恢复。
- [ ] AC6（R4）：自建零章节课程可按主题或课程知识库创建 Tutor 教材，课程响应持久返回绑定书籍标识和同步后的章节/页面映射。
- [ ] AC7（R3、R4）：有页面映射的章节可通过独立按钮进入正确 Tutor 页面；无映射章节显示可理解状态，不生成假链接。
- [ ] AC8（R4）：Tutor 创建失败不留下半绑定课程/章节，用户可重试；已有模板章节和进度不被破坏。
- [ ] AC9（R5）：在运行中的 Docker 环境完成真实学生全链路回归并记录结果；主应用、DeepTutor 和数据库保持健康。
- [ ] AC10：后端单元/API/集成回归、前端单元测试、Lint、构建，以及桌面与窄屏浏览器回归均通过。

## Out of Scope

- 教师端课程发布、学生选课审批、班级、付费课程和权限体系。
- 手工增删改或拖拽排序课程章节。
- 替换、重建或解绑已绑定的 Tutor 教材。
- 将 Tutor 页面完成度反向合并为课程章节完成度；本期课程进度继续由现有课程章节完成接口维护。
- Tutor/DeepTutor 自身算法、数据模型或界面重构。
