# 校园智能中控视觉稿提示词

- 用途：`ui-mockup`，16:9 桌面 Web 应用高保真首屏方向稿。
- 产品：真实名称“智汇校园”，竞赛演示中的校园 AI 操作界面。
- 构图：教师、学生、教务三块持久角色面板；中央教师任务轨展示“资料选择、学情分析、练习生成、课堂互动、教学建议”；友好 3D 机器人是次级系统守护者。
- 视觉：石墨深色面板、一像素分隔线、青绿色语义状态光、紧凑无衬线文字与等宽数字。
- 色彩：`#101418`、`#1C232B`、`#42D3B2`、`#DDE7EC`。
- 约束：Operate 模式；任务和状态优先；不做营销页；不使用真实学校、身份、客户或虚构指标；避免霓虹过载、装饰性玻璃拟态、游戏 HUD 和不可读小字。
