# 生长式知识花园学生端视觉稿提示词

- 用途：`ui-mockup`，16:9 学生端桌面 Web 应用高保真首屏方向稿。
- 产品：真实名称“智汇校园”，学生独立学习空间。
- 构图：课程知识树从交互教材生长，章节成为可导航分支；左侧课程章节，右侧 3D 机器人园丁与 AI 问答，下方学习轨迹和下一项练习；周围包含笔记、错题、练习和成果。
- 视觉：现代校园温室、植物标本册、几何枝条、透明温室层板、暖纸标签。
- 色彩：`#F7F0DD`、`#2E6B50`、`#D86F8B`、`#35485C`。
- 约束：Experience + Operate；生长状态必须对应真实阅读、问答和练习完成度；只显示学生端；避免儿童应用、纯装饰花边、幻想游戏、营销页和过度米色。
