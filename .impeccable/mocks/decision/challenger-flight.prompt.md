# 教学夜航仪表视觉稿提示词

- 用途：`ui-mockup`，16:9 桌面 Web 应用高保真首屏方向稿。
- 产品：真实名称“智汇校园”，以小型飞机夜航仪表体系转译教学操作台。
- 构图：六个仪表分别负责资料、分析、任务进度、风险、课堂互动和成果；教师、学生、教务角色选择；3D 机器人担任副驾驶；教师任务轨展示完整闭环。
- 视觉：哑黑仪表板、近黑表盘、白色航空数字、镭射绿指针、仅用于提醒的琥珀色。
- 色彩：`#090D12`、`#F0F4E8`、`#9BE46B`、`#E6A23C`。
- 约束：Operate 模式；熟悉操作和状态清晰优先；不使用真实学校、身份、客户或虚构指标；避免游戏 HUD、军事意象、驾驶舱拥挤、过度辉光和营销页结构。
