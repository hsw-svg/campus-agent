# 未来教学实验舱

Use case: ui-mockup

Asset type: 16:9 high-fidelity desktop web application first screen, competition product demo

Primary request: Design the “未来教学实验舱” visual direction for the real product “智汇校园”. This is an operating workspace UI, not a marketing landing page.

Scene/backdrop: a bright university teaching laboratory dashboard. Three transparent role work-pods labeled “教师”, “学生”, “教务” sit within one coherent desktop app shell. A small friendly premium 3D robot in the center physically guides anonymous document/sample cards into the teacher analysis pipeline. The teacher workflow is the visual priority.

Subject/UI content: persistent app navigation and credible interactive panels; show the teacher teaching loop as five connected steps: “资料选择 → 学情分析 → 练习生成 → 课堂互动 → 教学建议”. Include a clear anonymous workspace indicator, transparent sample cartridges, precision ruler/tick details, small status lights, restrained data visualizations, and task status chips. Use believable generic placeholder values only; do not invent a school, customer, endorsement, or real dataset.

Style/medium: high-fidelity professional product UI mockup with subtle cinematic 3D interface elements; clean, mature, precise, futuristic teaching instrument; glass used selectively for the three pods and sample cartridges, with solid readable panels elsewhere.

Composition/framing: straight-on desktop screen, 16:9 landscape. Dense but orderly product workspace. Teacher pod and central robot/pipeline command the middle; student and academic-affairs pods remain clearly accessible. Strong hierarchy, realistic spacing, legible UI density, no browser chrome, no device mockup, no floating marketing headline.

Lighting/mood: bright warm daylight laboratory, calm competence, approachable technology, premium competition-demo polish.

Color palette: warm white foundation, deep forest green primary, analytical blue secondary, restrained amber highlights; excellent text contrast.

Materials/textures: frosted transparent pods, clear sample cartridges, satin ceramic robot body, precision metal ticks, tiny status LEDs; avoid excessive gloss.

Text (verbatim): “智汇校园”; “教师”; “学生”; “教务”; “匿名工作空间”; “资料选择”; “学情分析”; “练习生成”; “课堂互动”; “教学建议”.

Constraints: Operate mode. Must look like a real usable React desktop application, not a concept poster. Preserve Chinese campus context. The robot is small, friendly, and functional—not a mascot dominating the screen. 3D supports workflow comprehension. No logos beyond the text product name. No fabricated school name, customer, claims, or identifiable personal data.

Avoid: marketing landing page, giant hero copy, neon cyberpunk, dark sci-fi cockpit, game HUD, cartoon children’s UI, oversized robot, excessive gradients, illegible tiny text, random English labels, watermark.
