# 知识引力场学生端视觉稿提示词

- 用途：`ui-mockup`，16:9 学生端桌面 Web 应用高保真首屏方向稿。
- 产品：真实名称“智汇校园”，学生独立学习空间。
- 构图：中央知识引力场代表当前难点；课程资料、交互教材、AI 问答、例题、练习和笔记沿轨道聚合；左侧课程章节，右侧 3D AI 学伴与问答，下方学习路径和下一项练习。
- 视觉：深空黑场、蓝白知识盘、金色光子环、精密透明控制层。
- 色彩：`#03050C`、`#E9F5FF`、`#52A9FF`、`#FF9B4A`。
- 约束：Experience + Operate；只显示学生端；课程导航、教材阅读、问答、练习和进度必须清晰；不使用真实学校、身份或虚构指标；避免科普海报、恐怖黑洞、赛博朋克拥挤、游戏 HUD 和营销页。
