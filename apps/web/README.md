# Campus Agent React 前端

该目录是 Campus Agent 当前使用的 React/Vite 前端，页面沿用新版视觉设计，工作空间、对话流式回复和附件上传通过 `/api` 接入 FastAPI 服务。

## Run Locally

**Prerequisites:** Node.js 20+


1. 在仓库根目录启动 API 服务（端口 `8000`）。
2. 安装依赖：`npm.cmd install`
3. 启动前端：`npm.cmd run dev`

生产检查：`npm.cmd run lint`、`npm.cmd run build`。
