# 同伴学友机器人

- 生成方式：内置 `image_gen`
- 用途：学生端“星图学习舱”同伴学友透明角色资产
- 参考：`ai-companion.webp` 仅用于统一高品质 3D 渲染语言，不复用其头部、身体、姿态或配件

## Prompt

Use case: stylized-concept. Create a completely new peer learning companion robot for a university student dashboard. Youthful compact synthetic robot with a rounded-square head, expressive circular eyes, soft modular shoulder shell resembling a casual campus jacket while remaining hard-surface robotics, asymmetric ear modules, friendly open-palms pose and floating linked learning tokens made only from abstract geometry. Polished stylized 3D animation-film character render, playful and collaborative, clearly non-human. Full character from head to upper thighs, three-quarter view, centered with generous padding. Pearl white, deep navy, mint and cyan. No text, letters, numbers, logos, watermark, cast shadow, contact shadow or reflection. Render on a perfectly flat solid `#ff00ff` chroma-key background with no gradient, texture, floor or lighting variation; do not use magenta on the subject.
