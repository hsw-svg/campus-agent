# 研究助理机器人

- 生成方式：内置 `image_gen`
- 用途：学生端“星图学习舱”研究助理透明角色资产
- 参考：`ai-companion.webp` 仅用于统一高品质 3D 渲染语言，不复用其头部、身体、姿态或配件

## Prompt

Use case: stylized-concept. Create a completely new research-assistant robot for a university student dashboard. Slender angular synthetic robot with a faceted visor head, one optical analysis lens, compact antenna sensor, articulated precise hands and a translucent holographic data slate with abstract charts and molecule-like points but no text. Polished stylized 3D animation-film character render with sophisticated hard-surface detail, analytical and curious, clearly non-human. Full character from head to upper thighs, three-quarter view, centered with generous padding and a narrow silhouette. Silver white, midnight navy, violet and electric blue. No text, letters, numbers, logos, watermark, cast shadow, contact shadow or reflection. Render on a perfectly flat solid `#ff00ff` chroma-key background with no gradient, texture, floor or lighting variation; do not use magenta on the subject.
